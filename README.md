# E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data using Python, Pandas, NumPy, Matplotlib, and PostgreSQL. The goal is to identify sales trends, top-selling products, customer spending patterns, and city-wise revenue.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- PostgreSQL
- Jupyter Notebook

## Dataset Description
The dataset contains 25 e-commerce orders with information about:
- Order ID and Order Date
- Customer Name
- City
- Product and Category
- Quantity
- Unit Price

## Project Tasks
- Data loading and inspection
- Data cleaning and preparation
- Revenue calculation
- City-wise sales analysis
- Category-wise sales analysis
- Product-wise revenue analysis
- Monthly sales analysis
- Top customer analysis
- SQL queries using PostgreSQL
- Data visualization using Matplotlib

## Key Business Insights
- Total Orders: 25
- Total Quantity Sold: 66
- Total Revenue: 726100
- Average Order Value: 29044
- Unique Customers: 15
- Highest Revenue Month: April
- Highest Revenue Order: Order ID 1018
- Highest Revenue Product: Laptop
- Best-Selling Product by Quantity: Chair

## Project Files
- `E-Commerce-Sales-Analysis/Data/` - Dataset and analyzed CSV files
- `E-Commerce-Sales-Analysis/SQL/` - SQL analysis queries
- `ecommerce_sales_analysis.ipynb` - Python analysis notebook

## Conclusion
This project demonstrates how Python and SQL can be used together to analyze sales data and generate useful business insights.
